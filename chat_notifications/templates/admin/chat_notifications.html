Endpoint Ownership Verification (GET Challenge)
CTFd proves and verifies endpoint ownership before streaming production events. CTFd will send a GET request with a ?token=<token> parameter. The endpoint must respond with JSON containing the token hashed with HMAC-SHA256 using the instance Shared Secret: {"response": hmac_sha256(SHARED_SECRET, token)}.
Security Headers & Signature Specification
Every webhook event dispatched by CTFd includes cryptographic security headers to prevent spoofing and replay attacks:
User-Agent: CTFd-Webhook
Content-Type: application/json
Ctfd-Webhook-Event: challenge.solved
Ctfd-Webhook-Signature: t=1616995588,v1=9e8cdd253434b74119ff44a119bb2d93e3b78a3a6a1a52d71e1bf70c36c55234
Signature Verification Algorithm:
The Ctfd-Webhook-Signature header consists of two parameters: t (Unix epoch timestamp) and v1 (hex HMAC-SHA256 digest). The hash is calculated as: hmac_sha256(SHARED_SECRET, f"{t}.{request_body}"). Receivers should verify the signature matches and optionally discard requests older than 300 seconds to protect against replay attacks.

Python Verification Script (Reference Implementation):
# receiver.py - Validates GET challenge and POST HMAC signatures
import hashlib, hmac, json
from flask import Flask, request, jsonify

app = Flask(__name__)
SHARED_SECRET = "{{ configs.shared_secret }}"

@app.route("/webhook", methods=["GET", "POST"])
def webhook_handler():
    if request.method == "GET":
        token = request.args.get("token", "")
        expected = hmac.new(SHARED_SECRET.encode(), token.encode(), hashlib.sha256).hexdigest()
        return jsonify({"response": expected})

    # Validate POST signature
    sig_header = request.headers.get("Ctfd-Webhook-Signature", "")
    parts = dict(kv.split("=", 1) for kv in sig_header.split(","))
    t, v1 = parts.get("t"), parts.get("v1")
    sig_input = f"{t}.{request.get_data(as_text=True)}"
    expected_v1 = hmac.new(SHARED_SECRET.encode(), sig_input.encode(), hashlib.sha256).hexdigest()
    if not hmac.compare_digest(v1, expected_v1):
        return "Invalid Signature", 401

    payload = request.get_json()
    return jsonify({"status": "received"}), 200
